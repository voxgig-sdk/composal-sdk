API

AgentThread

An agent's conversations: list or start one, or archive, compact or snooze it (actions).

Operations

Every route this entity exposes. Each route links to its own reference on this page.

Method Route SDK operation Returns
POST /api/v1/organizations/{organization_id}/agents/{id}/spark/threads/{thread_id}/archive create Thread archive state confirmed; history is retained
POST /api/v1/organizations/{organization_id}/agents/{id}/spark/threads/{thread_id}/compact create Native agent lifecycle response
POST /api/v1/organizations/{organization_id}/agents/{id}/spark/threads/{thread_id}/snooze create Snooze confirmed by the runtime. New activity in the thread also wakes it
POST /api/v1/organizations/{organization_id}/agents/{id}/spark/threads create Native agent lifecycle response
GET /api/v1/organizations/{organization_id}/agents/{id}/spark/threads list Native agent lifecycle response
