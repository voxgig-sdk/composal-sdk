signal.links.app string No
signal.links.external string No The provider deep link for an integration-sourced signal, the one absolute URL in this envelope, present only when the payload carries an http(s) external_url (docs §6e).

signal.links.subject string No
signal.occurred_at string Yes ISO8601 domain event time, what the UI displays and since filters on.

signal.recovery object No Recovered/resolved state folded from the resolution pairing (docs §6b/§6d). Present only when the pairing is satisfied, recovered for a runtime.health signal whose instance came back to running, resolved for an alert.fired whose event cleared. Absent otherwise.
signal.recovery.resolved_at string Yes
signal.recovery.state enum: recovered, resolved Yes

signal.resolution.resolved boolean Yes
signal.resolution.resolved_at string No
signal.resolution.resolved_by_signal string No Public id (sig_…) of the signal that cleared the condition.
signal.severity enum: info, warning, error, critical Yes Severity levels (docs §2, reusing AlertRule::SEVERITIES).
signal.source object Yes Provenance envelope (docs §6e), a sibling of the frozen payload. ALWAYS present, so a reader never branches on key presence: a Vex-produced signal renders provider: &quot;vex&quot; with null siblings.
signal.source.external_id string Yes The provider's own id for the thing the signal is about (a Sentry issue id).
signal.source.external_url string Yes Deep link to read the full event at the provider, Vex stores only a bounded reduction of it. Mirrored as links.external.
signal.source.integration_id string Yes The sint_… public id of the signal integration that ingested this signal. Null for native Vex and Slack sources; Slack uses its same-organization SlackInstallation subject.
signal.source.provider enum: vex, sentry, planetscale, slack Yes Who produced the signal (docs §6e). vex is every signal the platform emits itself. Slack is the native Composal app; the others are signal-integration adapters.
signal.subject_id string Yes
signal.subject_type string Yes Polymorphic pointer: AppDeployment, RuntimeInstance, AlertEvent, HostedApp, or SignalSubscription.
signal.summary string Yes One-line, kind-composed human sentence for the feed row (docs §6d, for example deploying → failed, 47× fp_9c1e77a4b2d0f331), server-authored so consumers never re-derive it from payload.
